# Commerce Intelligence design

## Mode
Operate: help a reviewer scan and filter evidence, then inspect definitions.

## Visual world
An editorial market ledger: warm mineral paper, ink typography, ruled tables, precise chart annotation, and one bright persimmon accent. The page feels like an analyst's well-kept fieldbook, not a generic terminal or finance template.

## Palette and type
- Paper `#f6f4ee`, white `#fffefa`, ink `#222822`, muted `#69716b`, rule `#e7e5dc`.
- Forest `#27483c` for stable series and persimmon `#d76a47` for selected emphasis; no meaning relies on color alone.
- Use bundled DM Sans for controls, Fraunces for primary headings, and IBM Plex Mono only for data labels; tabular numerals for metrics.

## Composition
Persistent desktop navigation, compact mobile top bar, a wide analytical canvas, sparse metric summaries, charts with visible axes, and data definitions alongside or immediately below interpretation.

## Interaction
Keyboard reachable navigation and filters, visible focus, range and region selection, clear selected states, accessible chart summaries, and CSV/JSON export of the current filtered view.
